# Attention Is All You Need

This project reproduces the "Attention Is All You Need" research paper through small, educational modules implemented in Jupyter Notebooks. Each module focuses on a specific component of the Transformer architecture, making it easier to understand and learn the concepts step by step.

## Purpose

The goal is to provide an educational implementation that breaks down the complex Transformer model into digestible pieces, allowing learners to:
- Understand each component of the Transformer architecture
- See how the pieces fit together
- Experiment with the code interactively
- Build intuition about attention mechanisms and neural language models

## Structure

The project is organized into modular Jupyter Notebooks, each covering different aspects of the Transformer model as described in the original paper.
